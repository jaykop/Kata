# 내장 SubGraph의 저장과 실행 연결

작성: 2026-10-06  
갱신: 2026-10-07  
유형: 진단·구현 기록  
대상: KataGraph·KataGraphEditor  
기준: #27의 데이터·편집 UI와 이번 저장 연결을 포함한 미커밋 작업 트리

## 배경과 결론

사용자가 LightAttack을 내장 SubGraph로 옮긴 뒤 인게임에서 공격이 실행되지 않는다고 보고했다.
이전 단계는 생성·편집 UI까지 구현했고 저장 빌드 연결은 후속 범위였다.
기존 평탄화는 외장 `SubGraph` 필드를 직접 읽으며, 부모 재구성 전에 내장 원본을 재구성하지 않았다.
단일 `UKataSubGraphNode`도 기존 Port In/Out 분기에 포함되지 않았다.
내장 먼저/부모 나중 저장과 단일 노드의 양쪽 연결을 구현했다. 사용자 에셋의 연결 구성과 실제 실행 결과는 미확인이다.

## 변경 내용

| 항목 | 이전 상태 | 반영 결과 |
|---|---|---|
| 저장 순서 | 부모만 재구성 | FKataGraphBuildContext가 저작 참조를 읽고 내장 원본부터 부모 순서로 재구성 |
| 저장 진입점 | Save 명령과 PreSave가 각각 호출 | Save 명령의 직접 호출 제거. 열린 에디터의 부모 패키지 PreSave에서 일반 저장·Save All 처리 |
| 원본 선택 | 외장 필드 직접 사용 | GetReferencedSubGraph로 활성 외장·내장 원본 선택 |
| 단일 SubGraph 노드 | In/Out 실행 분기에서 제외 | 진입은 사본 Entry로, 이탈은 사본 실행 노드 전체를 출발지로 하는 Alias로 연결 |
| 내부 Entry | 부모의 AllNodes 탐색에서 독립 시작점으로 취급될 수 있음 | 사본에 bIsSubGraphEntry를 저장하고 WaitingForEntry에서 제외 |
| 사본 정리 | 복제 EdGraph·껍데기 정리 | 함께 복제된 내장 저작 원본과 사본 Alias의 저작 참조도 정리 |
| 잘못된 참조 | 재구성 뒤 일부 오류만 진단 | 참조 순환·잘못된 소유/할당·진입 원본 Entry 누락은 전체 변경 전 검사 |
| 미선택 포트 | 평탄화에서 빠져 런타임에 남을 수 있음 | 실행 목록과 양쪽 연결에서 제거. 저작 노드는 보존 |

## 주요 결정과 이유

런타임은 부모에 펼친 노드·엣지를 실행한다. 별도 SubGraph 인스턴스는 추가하지 않는다.
같은 원본을 참조하는 여러 포트와 단일 노드는 사본 한 벌을 공유하며 내부 액션의 실행 상태는 기존 그래프 인스턴스가 관리한다.

내부 Entry를 부모의 시작점 탐색에 포함하면 빈 트리거의 내부 진입 엣지가 부모 입력을 우회할 수 있다.
이를 막는 플래그만 런타임 노드에 저장한다. 내부 Entry에 도달한 뒤의 조건·트리거·우선순위 해석은 기존 경로를 따른다.
기존 외장 사본에도 같은 규칙을 적용하므로 새 빌드 적용 후 부모를 다시 저장해야 한다.

외장 저작 참조도 순환 검사에 포함하되 부모 저장에서 다른 에셋을 재구성·저장하지 않는다.
외장은 저장된 실행 데이터를 복제한다. 내용의 최신성이나 미저장 변경 감지는 후속 단계다.
재구성 전 검사 실패는 기존 실행 데이터를 보존하지만 패키지 저장 자체를 취소하지 않는다.
로그 오류를 해결한 뒤 부모를 다시 저장해야 하며 파일 저장 성공만으로 실행 데이터 갱신 성공을 판단할 수 없다.

## 확인 범위와 결과

| 대상 | 확인 방법·수행자 | 결과 | 미확인 범위 |
|---|---|---|---|
| 공격 미실행 | 사용자 보고 | 내장으로 LightAttack 이동 후 공격 미실행 | 에셋 연결·트리거·조건, 정확한 재현 구성 |
| 저장 경로 누락 | 구현에 필요한 소스 읽기 | 외장 필드 직접 접근·내장 선행 재구성 없음·단일 노드 분기 누락 확인 | 사용자 환경의 다른 원인 |
| 이번 변경 | 에이전트 소스 구현 | 저장·실행 연결 반영 | 빌드·PIE·저장/재열기·Undo·GC·Game 빌드 |

빌드·테스트·별도 검사는 실행하지 않았다. 과거 외장 구현과 1단계 포트 테스트의 사용자 확인을 이번 변경의 성공 근거로 사용하지 않는다.

## 남은 제한과 후속 작업

- 재빌드 후 부모 Entry → SubGraph와 내부 Entry → LightAttack 연결을 확인하고 부모를 저장한 뒤 샘플 공격 입력으로 확인한다.
- 내장 저작 원본과 참조는 에디터 전용이다. Cook에서 실행 사본만으로 동작하는지는 사용자 Game 빌드 확인이 필요하다.
- 열린 그래프 에디터의 PreSave 경로에 연결했다. 에디터를 열지 않은 별도 에셋 재저장 도구와 Cook의 강제 재구성은 추가하지 않았다.
- 외장 원본 변경 감지·세대 기록과 전체 에셋 복제·붙여넣기·자동 배치 보완은 연결 계획의 후속 범위다.
  이후 [편집 동작 보완](2026-10-06-Embedded-SubGraph-Editing.md)에서 붙여넣기와 자동 배치를 연결했다. 외장 감지와 실제 복제 확인은 남아 있다.
- 특정 종료 노드·이름 있는 Entry/Exit와 포트별 독립 사본은 제공하지 않는다.
