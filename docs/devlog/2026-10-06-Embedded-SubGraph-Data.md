# 내장 SubGraph의 소유 데이터와 포트 참조 계약

작성: 2026-10-06  
갱신: 2026-10-07  
유형: 구현 기록  
대상: KataGraph의 내장 SubGraph 데이터·참조 계층  
기준: #27의 1단계 미커밋 소스 변경

## 배경과 결론

외장 그래프 에셋만 할당할 수 있던 포트에 내장 원본을 선택하는 데이터 계약을 추가했다.
사용자가 단계별 구현을 요청하고 1단계 브리핑 후 진행을 승인했다. 이번 범위는 소유 데이터,
선택 모드, 공통 참조 해석과 직접 참조 검증이다. 전체 내장 생성·편집 기능의 완성을 뜻하지 않는다.

## 변경 내용

| 항목 | 반영 내용 |
|---|---|
| 내장 원본 소유 | `UKataGraph::EmbeddedSubGraphs`를 에디터 전용 Instanced 목록으로 추가했다 |
| 표시 이름 | `GraphDisplayName`과 `GetGraphDisplayName()`을 추가했다. 내장은 표시 이름을 사용하고 빈 이름·외장은 UObject 이름을 사용한다 |
| 소유 판정 | `OwnsEmbeddedSubGraph()`가 직접 Outer와 목록을 함께 확인한다. 내장이 다시 내장을 소유하는 관계는 허용하지 않는다 |
| 포트 모드 | `bUseEmbeddedSubGraph`와 `FKataEmbeddedSubGraphReference`를 추가했다. 새 모드는 기본값 false다 |
| 기존 외장 필드 | `SubGraph` 이름·타입·기존 참조를 유지하고 외장 모드에서 표시하도록 메타데이터를 추가했다 |
| 참조 접근자 | `GetReferencedSubGraph()`가 활성 모드의 원본을 반환하며 유효하지 않은 참조는 nullptr로 처리한다 |
| 직접 검증 | 프로퍼티 변경에서 비활성 참조를 비우고 잘못된 내장 소유, 외장의 비에셋·자기·조상 참조를 해제한다 |
| 포트 제목 | 공통 참조 접근자를 사용해 활성 원본의 이름을 따른다 |

## 주요 결정과 이유

부모가 내장 원본을 소유하고 포트는 원본을 참조하도록 나눴다. 포트 참조에는 Instanced를 붙이지 않아
여러 포트가 같은 원본을 공유하는 계약을 유지한다. 원본 목록과 선택 데이터는 `WITH_EDITORONLY_DATA`,
접근자와 프로퍼티 변경 훅은 `WITH_EDITOR`에 두었다.

참조 판정은 노드의 캐시된 `Graph` 값보다 실제 Outer를 따른다. 저장 전·후와 복사 준비 과정에서
노드의 직접 Outer가 달라져도 바깥의 소유 그래프를 찾을 수 있기 때문이다.
순수 참조 접근자는 값이나 로그에 부작용을 남기지 않는다. 사용자 편집에서만 잘못된 선택을 해제하고 경고를 남긴다.

필드를 숨겨도 직렬화된 값은 남으므로 변경 훅에서 비활성 참조를 명시적으로 비운다.
이 정책은 1단계 브리핑에 포함되어 있다. C++ 직접 대입의 트랜잭션·변경 알림은 후속 편집 UI가 담당해야 한다.

## 확인 범위와 결과

이번 작업은 위 네 소스 파일의 구현과 관련 문서 반영이다.
에이전트는 빌드·자동화 테스트·별도 코드 검사·에디터 실행·직렬화·GC 동작 확인을 수행하지 않았다.
기존 #25의 사용자 확인을 이번 변경의 검증 결과로 사용하지 않는다.

2026-10-06 사용자가 "테스트 전부 예상대로 작동함"이라고 보고했다.
기존 SubGraph 구성이 없다는 설명에 따라 새 포트의 토글 표시·외장 기본값·자기 그래프 할당 거부를
안내한 뒤 받은 결과다. 기존 설정의 유지 확인은 생략했고, 내장 생성·저장·GC·런타임 전이는 확인 범위에 포함하지 않는다.
빌드의 별도 결과나 세부 로그는 받지 않았다.

## 남은 제한과 후속 작업

- 이 기록의 1단계에서는 내장 생성·선택 콤보·이름 변경·삭제·더블클릭·부모 복귀를 제공하지 않았다.
  후속 UI 구현과 확인 범위는 [내장 편집 UI 기록](2026-10-06-Embedded-SubGraph-Editor.md)을 따른다.
- 내장 먼저/부모 나중 재구성과 공통 참조 접근자의 평탄화 연결은 후속 저장 작업이다.
  이 기록 작성 시 `FlattenSubGraphs()`는 기존 `SubGraph` 필드를 직접 읽었다.
  같은 날 추가한 [저장·실행 연결](2026-10-06-Embedded-SubGraph-Runtime.md)이 이 제한과 참조 순환 검사 누락을 보완한다.
- 간접 SubGraph 의존 순환 검사, 붙여넣기 후 참조 정리, 외장 변경 감지는 후속 범위다.
- 내장 원본 목록과 포트 참조의 전체 에셋 복제·저장·Undo·GC 결과는 사용자 확인이 필요하다.
