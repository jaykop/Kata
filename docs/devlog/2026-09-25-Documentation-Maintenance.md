기준: 현재 작업 트리의 관련 소스·설정, 기존 사용자 확인 기록과 열린 이슈  
관련 이슈: [#11](https://github.com/jaykop/Kata/issues/11)·[#12](https://github.com/jaykop/Kata/issues/12)

## 배경과 결론

[문서 부채 진단](2026-09-24-Documentation-Diagnosis.md)의 선별 결과를 실제 문서에 반영했다.
현행 사용법과 과거 결정 이유가 한 상태 문서에 섞여 있던 내용을 목적별로 옮겼다.
현재 코드의 동작과 한계를 설명하며 새 기능·버그 수정을 구현한 것은 아니다.

새 결정 기록은 [에셋 모델](2026-09-25-Action-Asset-Model.md), [실행 수명](2026-09-25-Execution-Lifecycle.md),
[GAS·기본 태스크](2026-09-25-GAS-and-Tasks.md), [그래프 전이](2026-09-25-Graph-Transition.md)다.
최초 결정일을 알 수 없는 항목은 이번 정리일을 사용하고 과거 날짜나 검증 결과를 만들지 않았다.
Implementation-Status는 423줄에서 143줄의 현재 범위·한계·사용자 확인 요약으로 정리했다.
팩션·태그 설명서도 실제 플러그인 적용 범위·전역 판정·샘플 생성 연결을 보강했다.

## 상태 문서에서 옮긴 과거 유지보수 기록

다음은 기존 상태 문서가 보존하던 이력이다. 발생일·개별 수정 후 빌드 결과는 원문에 없어 미상이다.

- 액션 에디터가 존재하지 않는 CoreUObjectDelegates.h를 포함하던 경로를 UObjectGlobals.h로 수정했다.
- SKataPreviewViewport의 불완전한 FKataPreviewScene 타입 삭제에 대한 C4150 대응으로 소유 포인터를 FPreviewScene 기반 타입으로 바꿨다.
- 한국어 주석에서 폐기된 UKataInstance 표기와 지원하지 않는 UI 설명을 정리하고 AGENTS에 작성 기준을 추가했다.
  당시 기록은 주석 수정에서 실행 로직·문자열·리플렉션 메타데이터를 바꾸지 않았다고 명시했다.
- Slate double→float C4996 경고 6건은 과거 빌드 기록이며 이번에 현재 경고 수를 다시 확인하지 않았다.

## 근거와 확인 범위

확인한 범위는 공개 API·관련 구현·설정과 문서의 대조다. 주요 소스 링크는 각 설명서·결정 기록에 붙였다.
열린 이슈 #11·#12의 범위와 기존 사용자 확인 내용은 읽기 전용으로 조회했다.
템플릿을 제외한 루트 README와 docs 문서 30개의 로컬 링크·제목 앵커가 존재하는 대상을 가리키는지 확인했다.
빌드·UHT·자동화 테스트·UI 실행·별도 코드 검사는 수행하지 않았다.
과거 사용자 확인과 이번 문서 수정의 확인 범위를 [현재 상태](Implementation-Status.md#확인-범위)에 구분했다.

## 남은 제한

루트 모션 미이동·Pause 후 재시작 사용자 보고는 해당 환경에서 재현·해소를 확인하지 않았다.
소스에 있는 정상 경로 설명과 해당 보고를 구분해 [에디터 설명서](../manual/Editor-Usage.md#제한과-문제-해결)에 기록했다.
기존 에셋 자동 이전·BP 태스크·각 기본 태스크의 실행 확인도 문서 작성만으로 완료 처리하지 않는다.
이슈 진행 상태·종료는 이슈에서 관리하며 외부 댓글·라벨 변경은 사용자 확인 후 게시한다.
