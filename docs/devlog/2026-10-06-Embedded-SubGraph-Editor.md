# 내장 SubGraph의 편집 UI와 그래프 탐색

작성: 2026-10-06  
갱신: 2026-10-07  
유형: 구현 기록  
대상: KataGraphEditor의 내장 관리·선택·탐색  
기준: #27의 1·2단계 미커밋 소스 변경

## 배경과 결론

후속 변경: 사용자가 기대한 노드 생성·더블클릭 흐름에 따라 관리 패널을 제거했다.
현재 UI와 변경 이유는 [노드 중심 탐색 기록](2026-10-06-Embedded-SubGraph-Node-Navigation.md)을 따른다.
아래는 패널 기반으로 구현했던 당시의 기록이다.

1단계에서 추가한 내장 소유·참조 데이터에 생성·선택·편집 UI를 연결했다.
사용자가 1단계 포트 테스트 통과를 보고한 뒤 2단계 브리핑과 진행을 승인했다.
이번 범위는 원본 편집이며 내장 원본을 런타임 실행 데이터로 펼치는 저장 연결은 후속 단계다.

## 변경 내용

| 항목 | 반영 내용 |
|---|---|
| 루트와 현재 그래프 | `RootGraphAsset`은 제목·저장 대상, `EditingGraph`는 화면·Details·검색 대상으로 나눴다 |
| 관리 목록 | `SubGraphs` 탭에 New SubGraph, 이름 입력, Open, Delete를 추가했다 |
| 이름 계약 | 공백을 정리하고 빈 이름·대소문자를 무시한 중복 이름을 거부한다. UObject 이름은 유지한다 |
| 포트 선택 | 소유한 내장과 None만 제공하는 단일 선택 콤보를 등록했다. 서로 다른 소유자의 복수 선택에서는 비활성화한다 |
| 탐색 | 포트 더블클릭으로 내장을 같은 창에서 열거나 외장 에셋 에디터를 연다. 상단 버튼으로 부모에 돌아간다 |
| 화면 전환 | 선택과 검색 결과를 초기화하고 현재 그래프의 Details·검색을 표시한다. 세션 안에서 그래프별 화면 위치·확대율을 기억한다 |
| 삭제와 복구 | 부모의 저작 포트에서 해당 참조만 비운다. 포트·엣지는 남기며 삭제·참조 해제를 한 트랜잭션으로 묶는다 |
| 수명 | 루트·현재 그래프·편집 설정을 GC 참조 수집에 포함한다. 목록 항목과 콤보 후보는 약한 참조를 사용한다 |

## 주요 결정과 이유

내장은 별도 에셋 에디터로 열지 않고 루트가 소유한 그래프 사이에서 화면을 전환한다.
검색 위젯은 전환할 때 다시 생성해 이전 그래프의 결과가 남지 않도록 했다.
콤보를 열 때마다 소유 목록을 읽으므로 생성·삭제·Undo 후 후보 목록을 다시 반영한다.
포트 참조 변경은 PropertyHandle이 트랜잭션과 프로퍼티 변경 알림을 처리한다.

삭제한 원본을 즉시 파괴하지 않고 transient 패키지로 옮긴다. Undo가 보존한 객체를 복구할 수 있게 하면서,
소유 목록에서 제외된 저작 객체가 저장 패키지의 텍스트 수집 대상으로 남는 것을 피한다.
Undo/Redo 후에는 목록 결과에 맞춰 Outer를 복구하고 현재 편집 대상이 제거됐으면 부모로 돌아간다.
이 수명·저장 동작의 실제 결과는 사용자 확인이 필요하다.

## 확인 범위와 결과

2026-10-06 사용자가 제공한 빌드 로그에서 새 커스터마이제이션의 `AsShared` 모호성 오류가 발생했다.
`IPropertyTypeCustomization`이 이미 `TSharedFromThis`를 상속하므로 새 클래스의 중복 상속을 제거했다.
수정 후 재빌드는 확인하지 않았다. 같은 로그의 `GetObjectsWithOuter` 사용 중단 경고는 기존 평탄화 코드에 해당한다.

에이전트는 빌드·테스트·별도 검사를 실행하지 않았다. 2단계 UI 조작, 저장 후 재열기,
Undo/Redo·GC·전체 에셋 복제 결과는 미확인이다. 1단계의 사용자 테스트 통과를 2단계 검증으로 확대하지 않는다.

## 남은 제한과 후속 작업

- 내장 먼저/부모 나중 재구성, 공통 참조 접근자의 평탄화 연결과 패키지 저장 진입점 정리는 3단계다.
- 붙여넣기 후 내장 참조 정리와 저작 연결을 사용하는 자동 배치, 외장 사본 갱신 표시는 후속 범위다.
- 첫 구현은 부모 바로 아래 한 단계의 내장만 소유한다.
