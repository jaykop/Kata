# 내장 SubGraph의 붙여넣기와 자동 배치 보완

작성: 2026-10-06  
갱신: 2026-10-07  
유형: 구현·결정 기록  
대상: KataGraphEditor  
기준: #27의 데이터·UI·저장 연결과 이번 4단계 수정이 포함된 미커밋 작업 트리

## 배경과 결론

사용자가 다음 작업으로 안내한 4단계 편집 동작 보완을 승인했다.
기존 자동 배치는 저장용 `RebuildKataGraph()`를 호출하고 평탄화된 런타임 연결을 읽었다.
이 연결에는 저작 NodeMap에 없는 SubGraph 실행 사본이 포함되므로 현재 화면의 배치 자료로 사용할 수 없다.
붙여넣기는 대상 소유 그래프를 기준으로 내장 참조를 정리하지 않았고, 복사는 PrepareForCopying의 임시 Outer 변경을 남겼다.
배치 자료를 저작 핀에서 따로 모으고 붙여넣기·Undo 이후의 참조와 UI를 정리했다.

## 변경 내용

| 항목 | 반영 결과 |
|---|---|
| 배치 자료 | UKataGraphLayoutStrategy가 현재 EdGraph의 저작 노드·직접 핀 연결·엣지 노드 연결을 임시 배열과 맵으로 수집 |
| Tree | 방문 집합으로 한 노드당 부모 하나인 임시 숲 생성. 순환·합류·루트 없는 성분도 배치하되 실제 연결은 유지 |
| Force Directed | 전체 저작 연결을 유지하고 부모·자식 양방향 탐색으로 연결 성분을 한 번씩 배치. 다른 성분의 노드·엣지·주석은 이동 대상에서 제외 |
| 같은 페이지 붙여넣기 | 원본 내장 참조 유지. 내부 내용을 독립 복제하지 않음 |
| 다른 소유 페이지 붙여넣기 | 유효하지 않은 내장 참조 해제. 같은 이름 자동 선택이나 원본 가져오기 없음 |
| 외장 참조 | 대상에서도 유효하면 유지. 자기·조상 참조는 해제 |
| 실행 연결 | 붙여넣은 노드의 ParentNodes·ChildrenNodes·Edges와 Alias의 ResolvedSourceNodes 초기화. 저작 핀을 다음 저장에서 재구성 |
| Alias | 대상 페이지 저작 노드에 속하지 않는 Source Nodes 제거 |
| 복사 수명 | 텍스트 내보내기 직후 임시 Outer 변경 복구. 복제 불가 노드와 양끝이 선택되지 않은 엣지 제외 |
| Undo/Redo | 붙여넣은 노드·실행 설정 객체의 트랜잭션 연결. 기존 원본 목록·Outer 복구와 선택·Details 갱신에 검색 초기화 추가 |

## 주요 결정과 이유

저장 실행 데이터는 자동 배치를 위해 덮어쓰지 않는다. 배치의 런타임 노드 포인터는 저작 노드 식별에만 사용하고
연결은 배치 전략의 임시 자료에서 읽는다. 자료는 동기 배치 호출 동안 사용하며 신규 런타임 데이터나 모듈 의존성을 추가하지 않는다.

트리 알고리즘의 재귀 탐색은 순환 없는 임시 숲에만 적용한다. 여러 부모와 되돌아오는 연결은 화면에 그대로 남긴다.
Force Directed의 힘 계산은 성분의 저작 노드에만 적용하며 동일 성분을 여러 진입점 때문에 반복 이동하지 않는다.
겹친 좌표의 나눗셈과 크기 계산에는 0으로 나누지 않도록 경계를 둔다. 배치 품질 자체의 일반 개선은 이번 범위가 아니다.

포트만 복제하는 작업은 같은 원본 공유 계약을 따른다. 다른 소유자에 붙여넣은 원본을 자동으로 복제하거나
같은 이름으로 추정하면 사용자가 의도하지 않은 실행 내용을 만들 수 있으므로 선택을 비운다.
전체 에셋 복제는 기존 Instanced 소유 복제 경로를 유지하며 별도 객체 복제 훅은 추가하지 않는다.

## 후속 변경: SubGraph 노드의 독립 복제

사용자는 같은 원본을 가리키는 껍데기 노드를 복사할 이유가 있는지 지적했다.
Port In/Out의 참조 재사용이 이미 있으므로 SubGraph 노드는 내부 편집 단위 전체를 복제해야 한다는 정책으로 정정했고,
사용자가 "ㄱㄱ"로 구현을 승인했다. 이 결정은 앞선 표의 SubGraph 노드 공유·다른 부모에서 참조 해제 정책을 대체한다.
참조 Port In/Out만 복사하는 정책과 외장 에셋 참조 복사는 유지한다.

UKataEdNode에 클립보드용 Instanced 저작 사본과 원본 식별자를 추가했다.
CopySelectedNodes는 선택한 내장 SubGraph 원본마다 내부 내용을 한 번 복제해 텍스트에 담고,
내보내기 직후 임시 사본과 식별자를 원본 노드에서 제거한다. 원본을 수정·삭제하거나 에디터를 닫아도
텍스트의 복사 시점 내용으로 새 부모에서 복원할 수 있도록 객체 참조 경로만으로 붙여넣지 않는다.

KataEmbeddedSubGraphEditor::CopyForClipboard는 저작 EdGraph·노드·엣지·조건을 복제하고 실행 목록·연결·해석된 Alias 목록을 비운다.
불필요하게 복제된 저장 실행 사본은 transient로 옮긴다. PasteCopy는 대상 부모 소유의 새 내장으로 복제하고
표시 이름 충돌을 피하며 내부 노드 GUID를 새로 만든다. 액션 에셋과 유효한 외장 참조는 유지한다.
같은 선택의 SubGraph 노드와 Port In/Out은 원본 식별자별 새 사본 한 벌로 재연결한다.
붙여넣기를 반복하면 매번 다른 내장이 만들어지며 원본이나 앞선 붙여넣기 결과를 공유하지 않는다.

부모 목록·사본 객체·붙여넣은 노드의 변경을 Paste 트랜잭션 안에 기록하고 KnownEmbeddedGraphs에 등록해
기존 Undo의 Outer 복구 경로를 사용한다. 임시 클립보드 사본은 붙여넣기 뒤에도 노드 프로퍼티에서 제거한다.
중첩 소유를 허용하지 않으므로 내장 페이지에 SubGraph 노드를 포함한 선택을 붙여넣으면 전체 선택을 제거하고 트랜잭션을 취소한다.
내부 사본이 없는 이전 클립보드는 참조 공유로 돌아가지 않고 참조를 비우며 다시 복사하라는 로그를 남긴다.

잘라내기에서 참조만 복사한 원본을 필요로 하는 Port In/Out이 있을 때만 기존 원본 보존 예외를 사용한다.
SubGraph 본문도 복사한 원본은 마지막 참조 삭제 규칙으로 정리할 수 있다. 원본 보존 예외 때문에 남은 미참조 원본은
동일 부모에 독립 사본을 붙여넣은 뒤 정리한다. 새 붙여넣기·독립 편집·Undo/Redo·저장/재열기와 클립보드 재사용은 미확인이다.
이번 수정의 빌드·테스트·별도 검사는 실행하지 않았다. 구현 후 문서 반영 중 작업이 끊겼으며 2026-10-07 사용자 요청으로 이어서 반영했다.

빌드·테스트·별도 검사를 실행하지 않았다. 사용자의 앞선 "굳"은 구체적 실행 확인 항목이나 로그를 포함하지 않아
이번 변경이나 이전 저장 수정의 검증 성공으로 기록하지 않는다.
2026-10-07 독립 복제 변경 안내 뒤 사용자가 "테스트 완료"를 보고했다. 독립 복제 변경에 대한 사용자 확인 보고로 기록한다.
개별 확인 항목과 빌드 로그는 제공하지 않아 다른 부모 복사·반복 붙여넣기·Undo/Redo·클립보드 재사용의 세부 결과는 미상이다.
에이전트의 빌드·테스트·별도 검사 미실시 상태는 유지한다.

## 남은 제한과 후속 작업

- SubGraph 노드의 독립 복제·같은 선택의 포트 재연결·반복 붙여넣기·다른 부모로 붙여넣기·내부 액션/엣지와 Undo/Redo는 사용자 확인이 필요하다.
- SubGraph를 포함한 부모와 내부 페이지의 Tree·Force Directed 배치, 순환 연결·연결되지 않은 성분과 배치 Undo는 사용자 확인이 필요하다.
- 자동 배치는 저장을 대신하지 않는다. 편집 후 부모를 저장해 실행 데이터를 갱신한다.
- 참조 포트만 잘라내는 원본 보존 예외는 유지한다. SubGraph 노드는 클립보드 내부 사본으로 독립 복제한다.
- 외장 변경 감지·세대 기록·부모 갱신 필요 표시는 다음 단계다.
