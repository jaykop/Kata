# 액션 편집기 타임라인 표시 개선: 프레임 이동·진단 탭·막대 이름

작성: 2026-10-17  
갱신: 2026-10-17  
유형: 구현 기록  
대상: `KataEditor` 액션 편집기 타임라인(`FKataActionEditor`, `SKataTimeline`), [Editor-Usage](../manual/Editor-Usage.md)  
기준: #119 작업의 미커밋 작업 트리(이 기록과 같은 커밋)

## 배경과 결론

KataAction 편집기 사용 피드백 네 가지 가운데 세 가지를 [#119](https://github.com/jaykop/Kata/issues/119)로 묶어 구현했다.

- 태스크를 Disable할 때마다 타임라인 아래의 진단 영역이 늘어나 트랙 영역 높이가 바뀌었다.
- 태스크 막대에 아무 표시가 없어 어떤 태스크인지 보려면 왼쪽 이름 칸을 다시 봐야 했다.
- 재생 헤드를 한 프레임씩 옮길 방법이 없었다.

프리뷰 Self·Target을 BP 클래스 대신 에셋으로 지정하자는 나머지 피드백은 같은 목적의 [#118](https://github.com/jaykop/Kata/issues/118)에 맡겼다. 프리뷰 전용 DataAsset 방식은 #118의 설계 후보로 남아 있다.

## 변경 또는 진단 내용

| 항목 | 이전 상태 | 반영 결과 |
|---|---|---|
| 프레임 이동 | 재생·일시 정지·정지·반복만 있었다 | 정지 오른쪽에 이전·다음 프레임 버튼을 두었다. 30fps 기준 1/30초 프레임 경계로 이동하고, 재생 중이면 먼저 일시 정지한다 |
| 진단 표시 | 타임라인 아래 최대 100px 텍스트 영역이 진단 줄 수에 따라 늘어났다 | 별도 Diagnostics 탭에서 Error, Warning, Info 순으로 보여 준다. 탭 제목에 Error·Warning 개수를 붙인다 |
| 편집 오류 | 진단 문자열을 덮어써 다음 갱신까지 표시했다 | `EditFailed` Error 진단으로 탭 맨 앞에 넣고, 다음 갱신 때 해석 진단으로 다시 채운다 |
| 조작 안내 | 진단이 없을 때 진단 영역에 표시했다 | 타임라인 상단 도움말 아이콘의 툴팁으로 옮겼다 |
| 막대 표시 | 막대에 글자가 없었다. Inline 주석만 막대 안에 적었다 | 막대 안에 태스크 이름을 적는다. 길면 말줄임하고, 짧은 막대는 오른쪽 바깥에 적는다. Inline 주석은 이름 뒤 남는 폭에만 적는다 |
| 막대 글자색 | 막대 밝기에 따라 흰색이나 검은색이었다 | 화면에 보이는 막대 색의 보색을 쓰고 채도를 높인다. 밝은 막대에는 어두운 보색, 어두운 막대에는 밝은 보색을 쓴다 |
| 이름 글자 크기 | 모든 타임라인 글자가 `SmallFont`였다 | 그룹 제목과 태스크 이름(왼쪽 칸·막대)은 1.25배로 그리고 행 안에서 세로 가운데에 둔다. 왼쪽 칸은 글자 수 대신 칸 폭으로 자르고 `[P]`를 보존한다 |

## 주요 결정과 이유

- **탭 배치 이름을 바꾸지 않았다.** 레이아웃 이름 `KataAssetEditor_v3`을 바꾸면 사용자가 저장한 탭 배치를 모두 버린다. 그래서 이전에 저장한 배치에는 Diagnostics 탭이 자동으로 생기지 않고, Window 메뉴에서 연다.
  처음에는 타임라인 상단에 탭을 여는 `Errors N / Warnings N` 버튼을 두었으나, 탭이 생긴 뒤에는 중복이라는 사용자 판단에 따라 없애고 개수를 탭 제목으로 옮겼다. Info(예: 비활성 태스크 안내)는 고칠 문제가 아니므로 개수에 넣지 않는다.
- **프레임 레이트는 30fps로 고정했다.** 사용자가 정했다. 에셋별 프레임 레이트 설정은 범위에 넣지 않았다.
- **그룹 기능을 카테고리 자동 묶음으로 대체하지 않았다.** 사용자가 왼쪽 칸을 `KataTaskCategory`별로 묶고 그룹을 없애는 안을 물었다. 카테고리는 태스크의 종류를, 그룹은 액션의 어느 순간(한 번의 휘두르기에 속한 몽타주·판정·사운드·VFX)에 속하는지를 나타낸다. 저작할 때는 순간 단위로 찾는 경우가 많고, 그룹 데이터(`TimelineGroups`, `TimelineTopLevelOrder`)를 지우면 기존 에셋의 그룹·색·주석이 사라진다. 카테고리 보기는 필요하면 그룹과 별개의 표시 방식으로 다룬다.
- **왼쪽 칸과 막대의 이름 역할은 나누지 않았다.** 왼쪽 칸에 클래스 이름, 막대에 TaskName을 두는 안을 냈으나 정하지 않았다. 대신 막대 글자를 보색으로 구분했다.
- **보색은 sRGB 값으로 계산한다.** 처음에는 선형 색 값의 HSV에서 색상만 돌리고 명도·채도를 크게 낮춰, 분홍 막대의 글자가 보색으로 보이지 않았다. 화면에 보이는 sRGB 값으로 색상을 180도 돌리고 채도를 0.85 이상으로 올린 뒤 선형으로 되돌린다. 밝기 판정에는 Rec.709 상대 휘도를 쓴다(0.32 초과면 명도 0.35, 아니면 1.0). 채도가 0.15 이하인 회색 막대는 무채색으로 남겨 흰색으로 그린다.
- **이름 글자는 1.25배로 정했다.** 1.5배는 사용자가 크다고 판단해 줄였다.

## 남은 제한과 후속 작업

- 이전에 저장한 탭 배치에는 Diagnostics 탭이 없어 Window 메뉴로 한 번 열어야 한다.
- 이름 없는 태스크는 왼쪽 칸과 막대에 같은 클래스 이름이 보인다. 역할 분리는 결정하지 않았다.
- 프리뷰 Self·Target 지정 방식은 [#118](https://github.com/jaykop/Kata/issues/118)에서 다룬다.
