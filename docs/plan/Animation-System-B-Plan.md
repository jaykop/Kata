## 목적과 현재 상태

2026-10-18 사용자 결정으로, 두 참고 구조 방식의 애니메이션 체계를 각각 그 원본 에셋으로 구현해 보고 비교한 뒤 고른다.
첫 번째 참고 구조 방식(체계 A)은 [애니메이션 시스템 계획](Animation-System-Plan.md)이 다룬다. 이 문서는 두 번째 참고 구조 방식(체계 B)을 다룬다.

체계 B 의 목표는 이동 품질을 두 번째 참고 구조 수준으로 만드는 것이다. 참고 분석(비공개 자료)에서 확인한 이 구조의 특징은 다음과 같다.

- 이동 루프는 블렌드가 아니라 이동 단계(걷기·달리기·질주)별로 고정된 속도의 루프를 고른다.
- 출발·정지·이동 중 큰 방향 전환·곡선 이동은 각도별 전용 동작(전환 동작)으로 재생한다. 작은 방향 변화는 이동 단계별 회전 속도로 돈다.
- 무기를 든 이동은 앞뒤 한 쌍과 좌우 한 쌍을 위상을 맞춰 섞는 8방향 이동이다.
- 액션 연결은 체계 A 의 참고값보다 빠르고, 선입력 폭이 넓다(체계 A 계획 D4·D5 의 두 번째 참고값).

현재 상태: 두 번째 참고 구조의 원본 캐릭터 메시와 이동 동작을 샘플 콘텐츠로 가져오는 로컬 도구 경로가 있다(텍스처 제외). 이 체계의 Kata 구성 요소는 아직 없다. 다른 원본의 캐릭터에 리타게팅하는 경로는 관절이 꺾여 쓰지 않기로 했다(2026-10-18).

## 범위

- 포함: 이동 단계 루프와 단계별 회전 속도, 전환 동작(출발·정지·이동 중 선회·곡선)을 KataAction 으로 재생하는 구조, 전환 동작을 시작하는 장치, 무기를 든 8방향 이동, 체계 B 의 액션 연결 값, 체계 A 와 비교할 시험 구성.
- 제외: Motion Matching(별도 검토), 캡슐 움직임에 애니메이션을 맞추는 워핑 중심 구성(전환 동작이 입력에 늦게 반응한다고 판정될 때의 대안), 다른 원본 캐릭터로의 리타게팅, 원본 에셋의 텍스처·재질 정리(별도 작업), 원본 에셋과 추출 도구의 공개 저장소 반영.

## 확정 사항과 미확정 사항

| ID | 항목 | 구분 | 내용과 근거 또는 필요한 결정 |
|---|---|---|---|
| B1 | 공통 골격 | 확정 | 체계 A 계획의 D1·D2·D3·D13·D17 을 그대로 쓴다. ABP 상태 머신은 이동 루프만 맡고 전환 동작을 포함한 행동은 KataAction·KataGraph 가 맡는다(사용자 2026-10-18 두 체계 결정) |
| B2 | 시험 에셋 | 확정 | 체계 B 는 두 번째 참고 구조의 원본 모델·애니메이션을 그대로 쓴다. 다른 원본 캐릭터로 리타게팅하지 않는다(사용자 2026-10-18). 에셋은 공개 저장소에 올리지 않는다 |
| B3 | 이동 루프 | 결정 필요 | 이동 속도를 단계로 고정하고 단계별 루프를 고르는 안(원본 방식)과, 체계 A 처럼 연속 속도를 섞는 안 가운데 고른다. 단계 고정이면 "아주 느린 걷기"가 없어진다. 질주 단계를 둘지는 기획 판단이다 |
| B4 | 전환 동작 | 제안 | 출발·정지·이동 중 선회·곡선은 루트 모션 몽타주를 재생하는 KataAction 으로 둔다. 루트 모션 모드는 지금처럼 Montages Only 를 쓴다([루트 모션 커브](../manual/Root-Motion-Curve.md) 전제와 같음). 엔진 수정은 필요 없다 |
| B5 | 전환 시작 장치 | 제안 | 매 프레임 입력 방향과 몸 방향의 각도, 이동 속도, 직전 전환 뒤 경과 시간을 보고 전환 액션을 시작하는 장치를 둔다. 체계 A 의 PC 제자리 회전 시작(AS-3)과 같은 장치를 쓴다. 어느 모듈에 둘지와 KataGraph 의 입력 보관 계약(D3)과의 관계는 설계 때 정한다 |
| B6 | 회전 속도 | 제안 | 작은 방향 변화는 이동 단계별 회전 속도로 돈다. 전환 동작 없이 회전 속도만 낮추면 큰 각도 전환이 길어지므로 B4 와 함께 넣는다 |
| B7 | 무기를 든 이동 | 결정 필요 | 무기를 든 상태의 8방향 동기 블렌드를 쓸지와, 샘플 PC 가 무기를 넣은 상태를 가질지(이동 체계가 상태마다 다르다) 정한다 |
| B8 | 액션 연결 값 | 제안 | 체계 A 계획 D4·D5 에 적은 두 번째 참고값(더 빠른 연결, 약 0.3초 선입력)을 체계 B 의 샘플 액션에 쓴다 |
| B9 | 비교 기준 | 결정 필요 | 두 체계를 고를 기준(확인할 장면과 완료 조건)을 기획 판단으로 정한다 |

## 영향과 제한

- 모듈 경계: 전환 시작 장치와 새 조건은 Kata 기반 기능이므로 플러그인에 둔다. 위치는 설계 때 정한다(코어에 엔진 플러그인 의존을 더하지 않는다). 새 C++ AnimNode 는 만들지 않는다(D17).
- 루트 모션: 전환 동작은 몽타주 루트 모션만 쓴다. Root Motion From Everything 으로 바꾸지 않는다.
- 샘플: 체계 B 시험 PC 의 Blueprint·ABP·레이어·액션·그래프 에셋이 새로 생긴다. 원본 에셋은 공개 저장소의 `/Content/` 제외 규칙에 따라 Git 에 올라가지 않는다.
- 체계 A 와 공유: 전환 시작 장치(MB-2 = 체계 A AS-3 의 시작 조건), 액션 연결 규약(체계 A AS-5).

## 사용자 확인 항목

- MB-1~MB-8 은 각 완료 조건의 PIE 확인이 필요하다. 이 문서는 빌드·테스트 실행 권한을 주지 않는다.
- B3·B7·B9 는 기획 결정이 필요하다.
