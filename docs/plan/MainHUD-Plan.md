# MainHUD 기반과 락온 마커 계획

작성: 2026-10-04  
갱신: 2026-10-04  
연결 이슈: [#33](https://github.com/jaykop/Kata/issues/33)  
현재 상태 근거: [HUD 사용법](../manual/HUD.md), 연결 이슈  
대체 관계: 없음

## 목적과 범위

플레이 중 락온한 지점을 알아볼 수 있도록 플레이어 화면에 MainHUD와 마커를 제공한다.
사용자가 이번 범위를 MainHUD 기반과 락온 마커로 확정했다. HP·스태미나·적 체력바는 제외한다.

## 설계

- HUD 생성·정리는 KataFramework 컨트롤러, 표시와 Blueprint 확장은 `UKataMainHUD`가 맡는다.
- 폰 교체 때 타게팅 구독을 옮긴다. 락온 변경은 같은 경로에서 HUD와 카메라로 전달한다.
- 기본 마커는 별도 에셋 없이 제공하며 Widget Blueprint에서 교체할 수 있다.
- 지점은 약한 참조로 저장하고, 카메라와 지점 이동은 투영할 때 읽는다. 화면 밖·뒤쪽은 숨긴다.
- 전역 메시지 라우터와 새로운 위성 의존성을 도입하지 않는다. Framework에 UMG·SlateCore 의존성을 추가한다.

## 완료 조건과 사용자 확인

빌드 후 획득·해제·지점 전환·대상 파괴·폰 교체, 해상도·DPI 변경과 화면 밖 마커 숨김을 사용자가 확인한다.
구현과 실제 확인 상태는 이슈에서 관리하며 에이전트가 빌드·테스트를 실행하지 않는다.
