대체 관계: 기존 월드 재실행 후 몽타주 위치 보정 방식을 대체했다. 이 계획의 직접 포즈 평가 방식은
2026-09-24 사용자 결정으로 다시 실행 시뮬레이션 방식에 대체됐다(아래 "탐색 방식 변경"). 사용자가 실행 확인을 마치고 푸시했다.

## 목적과 현재 상태

타임라인을 임의 순서로 이동해도 해당 시각의 몽타주 포즈를 즉시 표시한다.

현재는 탐색할 때마다 그 시각까지 실제 실행을 한 프레임 안에서 시뮬레이션한다. 2026-09-24 사용자가 빌드·실행 확인을 마쳤다.

## 탐색 방식 변경 (2026-09-24)

사용자가 두 가지를 보고했다. 드래그하는 동안 포즈가 갱신되지 않고, 탐색한 루트 모션 위치가 재생했을 때와 다르다.
직접 포즈 평가는 루트 모션을 계산으로 적용하므로 착지, 걷기 중 바닥 추종, 충돌, 태스크 종료 뒤 위치 유지를 재현할 수 없다.
사용자는 드래그로 재생 헤드가 바뀔 때마다 시뮬레이션하는 방식을 선택했다.

| 항목 | 결정 |
|---|---|
| 탐색 | 프레임당 마지막 요청 한 번만 처리한다. 앞으로 가면 이어서 진행하고, 뒤로 가면 장면을 다시 만들어 0초부터 진행한다. 한도는 액션 전체 길이다. |
| 결과 | 포즈·블렌드·섹션 진행·루트 모션·캡슐·충돌·다른 태스크 효과가 재생 결과와 같다. Blend In 구간은 몽타주 에디터의 단독 포즈와 다를 수 있다. |
| Play | 탐색 결과가 살아 있는 인스턴스이므로 그대로 이어 재생한다. 이전의 예약 재생은 제거했다. |
| 소리 | 탐색 진행 중에는 프리뷰 월드 소리를 끈다. |
| 드래그 중 갱신 | 탐색 캡처에 PreventThrottling을 쓰고 클라이언트 Invalidate로 다시 그리기를 요청한다. |
| 제거 | UAnimPreviewInstance 교체, 루트 모션 역산, KataEditor의 AnimGraph 의존성. |
| 비용 | 뒤로 탐색하는 비용은 목표 시각에 비례한다. 긴 액션을 뒤로 드래그하면 끊겨 보일 수 있다. |
| 동기 진행 | 한 프레임 안의 추가 World Tick이 액터를 진행하도록 단계마다 GFrameCounter를 올린다. 앞선 bIsAutonomousTickPose 처리는 이 방식으로 대체했다. 프리뷰 메시는 AlwaysTickPoseAndRefreshBones로 둔다. |

아래 표와 작업 목록은 직접 포즈 평가 방식 당시의 기록이다. 시간 변환·표시 대상·Notify 억제·루트 모션 계산 항목은
위 결정으로 더 이상 현재 동작이 아니다.

## 범위

- 포함: Play Montage 저작용 포즈 탐색, 엔진 프리뷰 인스턴스 통합, 재생·정지 전환과 자원 정리.
- 제외: 런타임 몽타주 재생 규칙 변경, 자체 섹션 재생기·애니메이션 샘플러 구현, 새 테스트 코드.
- 기존 Play의 GAS·AnimBP·루트 모션 실행은 유지할 대상으로 둔다. 포즈 탐색에서 월드 상태까지
  임의 시각으로 복원하는 기능은 동일한 문제로 간주하지 않는다.

## 확정 사항과 미확정 사항

| 항목 | 구분 | 내용과 근거 또는 필요한 결정 |
|---|---|---|
| 탐색 결과 | 확정·구현 | 섹션 연결과 이동 방향에 관계없이 지정 시각의 에셋 포즈를 직접 평가한다. |
| 엔진 재사용 | 구현 완료·검증 미실시 | KataEditor에서 UAnimPreviewInstance를 쓰고 AnimGraph는 Editor Private 의존성이다. |
| 시간 변환 | 구현 완료·검증 미실시 | 몽타주 시각 = Clamp(StartSection 시작 위치 + (헤드 시각 − 태스크 StartTime) × PlayRate × RateScale, 0, 몽타주 길이). StartSection 미지정은 0. Next Section은 따라가지 않는다. |
| 저작 시각과 실행 시각 | 구현 완료·검증 미실시 | 태스크 StartTime을 기준으로 하며 실제 StartedAtKataTime과 혼용하지 않는다. |
| 경계와 구간 밖 | 구현 완료·검증 미실시 | 시작·끝 포함 태스크 구간에서 표시한다. 몽타주 길이를 넘으면 마지막 포즈. 순간·Single Frame은 시작 시각만 표시한다. 구간 밖에는 원래 애니메이션 설정으로 복귀한다. |
| 겹치는 태스크·다중 Slot | 일부 완료 | 가장 늦게 시작한 태스크를 표시하며 동률은 해석된 배열의 나중 항목이 우선한다. 엔진 단일 에셋 프리뷰의 첫 Slot을 사용한다. 게임 AnimBP 합성은 범위 밖이다. |
| Notify·부작용 | 구현 완료·검증 미실시 | 포즈 탐색은 Notify, 종료 정책, GE, 게임플레이 이벤트를 실행하지 않는다. |
| 루트 모션 | 구현 완료·검증 미실시 | 사용자 후속 요청으로 Start Section부터 현재 위치까지 엔진이 추출한 이동·회전을 적용한다. 두 번째 후속 요청으로 적용 대상을 메시 상대 Transform에서 액터(캡슐)로 바꿨다. 월드 Tick·충돌·중력은 재현하지 않는다. |
| 스크럽 뒤 Play | 구현 완료·검증 미실시 | 재생 헤드 시각까지 한 프레임 안에서 동기 진행한 뒤 이어 재생한다. 한도는 액션 전체 길이다. |

## 영향과 제한

- 런타임의 ASC/Montage_Play, 종료 정책, 태스크 자원 정리 계약은 바꾸지 않는다.
- 새 직렬화 필드는 기본 해결책에 필요하지 않다. 프리뷰 상태는 에디터가 소유한다.
- 게임 AnimBP의 레이어·IK 결과와 몽타주 에셋 단독 포즈는 다를 수 있다. additive와 선택 Slot은 엔진 프리뷰의 계약을 따른다.
- 다른 작업자의 미커밋 변경이 존재한다. 실제 구현을 시작할 때 관련 파일의 최신 상태를 읽고 이번 진단 이후 변경도 보존한다.

## 사용자 확인 항목

구현 후 사용자가 빌드와 화면 확인을 담당한다. 아래 목록은 실행 결과가 아니라 완료 기준이다.

- 단일 섹션과 여러 섹션에서 같은 시각을 직접 입력·순방향·역방향으로 지정했을 때 포즈가 일치한다.
- A→C, 연결 단절, 자기 반복과 순환 연결에서도 에셋상 B 구간을 직접 확인할 수 있다.
- 첫 프레임, 섹션 경계, 마지막 프레임, Blend In 구간에서도 포즈가 표시된다.
- StartSection, PlayRate, RateScale이 시간 변환 정책대로 반영된다.
- 태스크·액션 종료 뒤 되돌리기, 긴 거리 점프와 빠른 왕복에서 상태 소실·추격 지연이 없다.
- Notify·종료 정책이 포즈 탐색으로 실행되지 않으며, 탐색 후 Play·Stop·Reset에서 원래 프리뷰가 복원된다.
- 일반 Play의 Idle·몽타주 블렌드·루트 모션·GAS 실행을 별도로 확인한다.
- 루트 모션 몽타주에서 위치·회전·역방향 탐색·구간 밖 복원이 맞는지 확인한다.
- 일반 재생 중 Pause→Play와 Current Time 포커스 이동 후 Pause→Play가 남은 구간을 이어가는지 확인한다.
